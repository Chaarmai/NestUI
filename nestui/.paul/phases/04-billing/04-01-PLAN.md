<objective>
## Goal
Implement Stripe subscription billing with plan selection UI, checkout flow, and webhook handling so agencies can subscribe to Free/Pro/Agency plans.

## Purpose
Billing is the monetization layer. Without it, Nest UI has no revenue. Agencies need to select a plan, enter payment, and have their workspace automatically upgraded.

## Output
- Stripe client library (`src/lib/stripe.ts`)
- Billing hook (`src/hooks/useBilling.ts`)
- Full Billing page with plan cards and current plan display
- Supabase Edge Functions for checkout session creation, Stripe webhook handling, and customer portal session
</objective>

<task type="auto">
  <name>Task 3: Create Supabase Edge Functions for checkout, webhook, and portal</name>
  <files>supabase/functions/create-checkout/index.ts, supabase/functions/stripe-webhook/index.ts, supabase/functions/create-portal-session/index.ts</files>
  <action>
    Create `supabase/functions/create-checkout/index.ts`:
    - Accept POST with { workspaceId, priceId } body
    - Verify auth (Supabase JWT from Authorization header)
    - Create or retrieve Stripe customer (using workspace email or stripe_customer_id)
    - Create Stripe Checkout Session in subscription mode
    - Set success_url and cancel_url to VITE_APP_URL/billing?session_id={CHECKOUT_SESSION_ID}
    - Store metadata: { workspaceId }
    - Return { url: session.url }
    - Uses `stripe` npm package server-side (Deno import from esm.sh)

    Create `supabase/functions/stripe-webhook/index.ts`:
    - Accept POST with raw body
    - Verify Stripe webhook signature using STRIPE_WEBHOOK_SECRET env var
    - Handle events:
      - `checkout.session.completed`: Update workspace plan based on price, set stripe_customer_id
      - `customer.subscription.updated`: Update workspace plan if price changed
      - `customer.subscription.deleted`: Reset workspace plan to 'free'
    - Map Stripe Price IDs to plan names via a lookup object
    - Return 200 on success

    Create `supabase/functions/create-portal-session/index.ts`:
    - Accept POST with { workspaceId } body
    - Verify auth
    - Fetch workspace to get stripe_customer_id
    - Create Stripe Billing Portal Session
    - Set return_url to VITE_APP_URL/billing
    - Return { url: session.url }
  </action>
  <verify>npx tsc --noEmit passes (edge functions use Deno types, verify no syntax errors)</verify>
  <done>AC-2 satisfied: full checkout flow. AC-3 satisfied: webhook handles subscription lifecycle. AC-4 satisfied: portal session creation.</done>
