<objective>
## Goal
Add a persistent onboarding checklist to the Dashboard that guides new users through setup steps: create workspace, connect GHL, install snippet, and apply first theme. Auto-dismisses when all steps are complete. Includes a manual dismiss option.

## Purpose
New users need clear guidance on what to do after signup. The checklist reduces time-to-value by walking agencies through the exact steps to get Nest UI working on their GHL dashboard.

## Output
- useOnboardingChecklist hook deriving step completion from workspace state
- OnboardingChecklist component with progress bar and clickable steps
- Dashboard.tsx updated to show checklist above theme grid for incomplete users
</objective>

<task type="auto">
  <name>Task 1: Create useOnboardingChecklist hook and OnboardingChecklist component</name>
  <files>src/hooks/useOnboardingChecklist.ts, src/components/dashboard/OnboardingChecklist.tsx</files>
  <action>
    **useOnboardingChecklist hook:**
    - Reads workspace from useAppStore
    - Defines 4 steps, each with: id, title, description, completed (boolean), action (route string or null)
      1. "Create workspace" — completed if workspace exists (always true on dashboard)
      2. "Connect GoHighLevel" — completed if workspace.ghl_connected === true — action: "/onboarding"
      3. "Install snippet" — completed if workspace.ghl_connected === true (proxy: they need connection first) — action: null (scroll to snippet in LeftPanel)
      4. "Apply a theme" — completed if workspace.active_theme_id !== 'obsidian' (default) OR workspace.theme_applied_at is not null — action: null (already on theme grid)
    - Computes: completedCount, totalCount, allComplete, progressPercent
    - Manages dismissed state via useState (session-only, resets on reload)
    - Returns: steps, completedCount, totalCount, allComplete, progressPercent, dismissed, dismiss()

    **OnboardingChecklist component:**
    - Props: none (uses useOnboardingChecklist internally)
    - If allComplete or dismissed, return null
    - Renders a card matching app design (rounded-xl, border-nestui-border, bg-nestui-bg1)
    - Header: "Getting Started" title + dismiss X button + progress text "N of 4 complete"
    - Progress bar: thin bar showing progressPercent with nestui-blue fill
    - Step list: vertical list of steps, each with:
      - Checkmark circle (green filled if complete, empty border if not)
      - Title (text-nestui-text if incomplete, text-nestui-text2 with line-through if complete)
      - Description (text-xs text-nestui-text3)
      - If step has an action route and is incomplete: show as Link with hover highlight
    - Animation: subtle opacity transition when dismissing (not required, nice-to-have)
  </action>
  <verify>npx tsc --noEmit — zero errors</verify>
  <done>AC-1 and AC-2 satisfied: Hook derives completion, component renders checklist with progress</done>
