<objective>
## Goal
Build sub-account management so agencies can add GHL sub-accounts, assign themes per sub-account, and push themes to individual accounts — with plan-based limits enforced.

## Purpose
Sub-accounts are core to the Agency plan value prop. Agencies manage multiple GHL locations and need per-account theming. Without this, the product only supports single-account use.

## Output
- `useSubAccounts` hook for CRUD operations
- Sub-accounts page with list, add, and per-account theme assignment
- Plan limit enforcement (Free: 1, Pro: 5, Agency: unlimited)
- Navigation update to include sub-accounts link
</objective>


## AC-2: Add Sub-Account
```gherkin
Given a user clicks "Add Sub-Account"
When they fill in the name and GHL account ID and submit
Then a new sub-account is created in Supabase
And it appears in the list
And if they've reached their plan limit, the add button is disabled with a message
```

## AC-3: Per-Account Theme Assignment
```gherkin
Given a user clicks on a sub-account's theme selector
When they pick a theme from the dropdown
Then the sub-account's active_theme_id is updated in Supabase
And the card reflects the new theme
```

## AC-4: Plan Limit Enforcement
```gherkin
Given a user on the Free plan with 1 sub-account
When they try to add another sub-account
Then they see a message explaining they need to upgrade
And the add button is disabled
```
