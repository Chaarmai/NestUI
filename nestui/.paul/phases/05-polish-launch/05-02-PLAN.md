## Goal
Build an AI Theme Generator that lets Pro and Agency users describe a theme in natural language, generates a full ThemeColors palette via Claude API, and shows a live preview they can save and apply.

- Supabase Edge Function calling Claude API to generate theme colors from a text prompt
- Generator page with prompt input, live preview, and save/apply flow
- Plan gating (Pro/Agency only) with upgrade CTA for Free users
- New route at /generate

<task type="auto">
  <name>Task 1: Create generate-theme Edge Function and useThemeGenerator hook</name>
  <files>supabase/functions/generate-theme/index.ts, src/hooks/useThemeGenerator.ts</files>
  <action>
    **Edge Function (supabase/functions/generate-theme/index.ts):**
    - Accept POST with `{ prompt: string, workspaceId: string }`
    - Verify workspace exists and plan is 'pro' or 'agency' (query workspaces table)
    - Call Claude API (Anthropic SDK via fetch to https://api.anthropic.com/v1/messages) with a system prompt that:
      - Instructs Claude to generate a ThemeColors object (bg, bg1, bg2, surface, border, accent, accentSoft, text, text2, text3)
      - Also generate: name (string), mode ('dark' | 'light'), description (string), swatch (CSS gradient string)
      - Output must be valid JSON matching the Theme interface shape (minus id, nav, tags)
    - Parse the response JSON, validate all 10 color fields exist
    - Return the generated theme data
    - Use ANTHROPIC_API_KEY from environment (Deno.env.get)
    - Handle errors: invalid plan → 403, bad prompt → 400, API failure → 502
    - Use claude-sonnet-4-6 model for speed/cost balance

    **Hook (src/hooks/useThemeGenerator.ts):**
    - State: generatedTheme (Theme | null), generating (boolean), error (string | null)
    - generateTheme(prompt: string): calls Edge Function via supabase.functions.invoke('generate-theme', { body: { prompt, workspaceId } })
    - Parses response into a Theme object, assigning a temporary id like `custom-${Date.now()}`
    - Sets nav to 'Custom', tags to ['custom', mode]
    - Computes swatch from accent + bg colors
    - applyGeneratedTheme(): calls workspace.applyTheme with the generated theme ID
    - clearGenerated(): resets state
  </action>
  <verify>npx tsc --noEmit passes with no errors for both files</verify>
  <done>AC-2 satisfied: Edge function processes prompt and returns ThemeColors via Claude API; hook manages generation state</done>
</task>
